# Как локализовать интерфейс NOC

Выберите язык интерфейса через глобальный параметр `language`. NOC поддерживает `en`, `ru` и `pt_BR`. После изменения параметра перезапустите затронутые сервисы. Описание параметра приведено в [справочнике конфигурации](../config-reference/global.md#language).

## Добавление и изменение переводов Python

Переводы Python хранятся в YAML-каталогах со стабильными ключами: `src/noc/i18n/en.yml`, `src/noc/i18n/ru.yml` и `src/noc/i18n/pt_BR.yml`.

1. Добавьте ключ и английский текст в `en.yml`.
2. Добавьте тот же ключ с переводом в каждый каталог языка, который обновляете. Если ключа нет в каталоге языка, используется английский текст.
3. Сохраняйте ключи в алфавитном порядке. Тесты каталога проверяют сортировку.
4. Вызывайте перевод в Python через `t()`:

   ```python
   from noc.core.i18n import t

   error = t("msg-prefix-not-found")
   ```

Выбирайте префикс ключа по назначению текста:

| Префикс | Назначение |
| --- | --- |
| `btn-` | Текст кнопки, например `btn-print` |
| `msg-` | Сообщения пользователю и ошибки |
| `label-` | Подписи полей форм и заголовки полей карточек |
| `help-` | Подсказки и всплывающие подсказки |
| `choice-` | Варианты в списке выбора |
| `header-` | Заголовки колонок таблиц и отчётов |
| `title-` | Заголовки, кроме названий приложений |
| `status-` | Состояния и статусы |
| `app-title-`, `app-group-`, `nav-` | Названия приложений, группы меню и навигационные подписи |

В Jinja2-шаблонах карточек используйте `t()` без импорта:

```jinja
<b>{{ t("label-name") }}</b>
```

Передавайте значения именованными аргументами. Для сообщений, форма которых зависит от числа, используйте ICU plural pattern; не соединяйте перевод с числительным при помощи конкатенации.

```yaml
msg-item-count: "{count, plural, one {# предмет} few {# предмета} many {# предметов} other {# предмета}}"
```

```python
t("msg-item-count", count=item_count)
```

Для русского языка указывайте формы `one`, `few`, `many` и `other`. Во всех каталогах используйте синтаксис ICU MessageFormat.

## Перевод строк JavaScript

В JavaScript по-прежнему используется `__()` и gettext-каталоги:

```javascript
__("Save")
```

После изменения строк JavaScript извлеките и обновите каталог Web:

```bash
./noc translation extract web
./noc translation update web
```

Отредактируйте `src/noc/services/web/translations/<язык>/LC_MESSAGES/messages_js.po`, затем скомпилируйте каталог:

```bash
./noc translation compile web
```

Компиляция записывает JSON-каталог JavaScript в `ui/web/translations/<язык>.json`. Команды `translation` обрабатывают gettext-каталоги и не извлекают Python-ключи `t()`. Перед извлечением новый JavaScript-файл должен быть добавлен в Git: команда обходит файлы из `git ls-files`.

## Проверка каталогов

После изменения YAML-переводов запустите тесты каталогов:

```bash
./scripts/run-dev pytest tests/i18n/test_catalog.py
```

Тесты проверяют загрузку каждого настроенного каталога, совпадение его ключей с английским каталогом и алфавитную сортировку ключей.
