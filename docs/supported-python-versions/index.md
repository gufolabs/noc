# Supported Python Versions

NOC supports the following Python versions:

| NOC Release | Supported Python Versions |
| ----------- | ------------------------- |
| 24.1        | 3.10–3.11                 |
| 25.1        | 3.11                      |
| 26-dev      | 3.13                      |

For newer releases, NOC aims to support the latest current Python version and to remove support for Python versions that have reached end of life (EOL). For Python version lifecycle details, see the [Python Developer's Guide](https://devguide.python.org/versions/).
