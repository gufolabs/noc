# Restricted Dependency Licenses

## Scope

## Scope

All external components required for development, building, distribution, deployment and operation of the NOC project.

## Requirements

Dependencies using licenses from the restricted list **MUST** be reviewed and approved by the Gufo Labs legal team before adoption.

The following licenses require additional review:

### Weak copyleft licenses

- LGPL-2.0
- LGPL-2.1
- LGPL-3.0

### File-level copyleft licenses

- MPL-1.1
- MPL-2.0

### Other open-source licenses requiring review

- EPL-1.0
- EPL-2.0
- CDDL-1.0
- CPL-1.0
- OSL-3.0

### Dual-licensed dependencies

Any dependency distributed under multiple licenses **MUST** be reviewed unless the selected license variant is included in the approved license list.

### Custom or uncommon licenses

Any license not included in approved or prohibited lists **MUST** be treated as restricted and reviewed before use.

## License Review

The Gufo Labs legal team review **SHOULD** evaluate:

- compatibility with NOC licensing model;
- compatibility with derivative products;
- redistribution obligations;
- modification obligations;
- source disclosure requirements;
- attribution requirements;
- compatibility with other dependencies.

## Why?

Some licenses provide useful open-source components while introducing additional obligations.

A separate review process allows the project to use such dependencies when appropriate while avoiding unexpected legal constraints.
