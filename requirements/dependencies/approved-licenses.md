# Approved Dependency Licenses

## Scope

All external components required for development, building, distribution, deployment and operation of the NOC project.

## Requirements

Dependencies using licenses from the approved list **MAY** be used without additional legal review, provided that all other dependency requirements are satisfied.

The following licenses are approved:

### Permissive licenses

- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- MIT
- ISC
- Zlib
- BSL-1.0

### Public domain / equivalent licenses

- CC0-1.0
- Unlicense

The approved license list **SHOULD** prefer licenses that:

- allow redistribution;
- allow modification;
- allow commercial usage;
- do not impose source disclosure obligations on derivative products.

Licenses not included in this list **MUST** be reviewed by Gufo Labs legal team before adoption.

## Why?

Permissive licenses provide broad compatibility with the NOC distribution model and derivative product ecosystem.

A predefined approved list reduces unnecessary legal review while maintaining predictable licensing conditions.
