# Documentation Quality Standards

## Scope

All documentation and comments maintained as part of the NOC project.

## Requirements

All documentation and comments MUST satisfy the documentation quality requirements.

Common documentation quality requirements MUST apply to all supported languages.

Language-specific requirements MAY define additional rules for a particular language.

## Why?

Documentation quality standards ensure that project knowledge is clear, consistent, and maintainable.

They reduce ambiguity and improve understanding of the system by both humans and automated tools.
