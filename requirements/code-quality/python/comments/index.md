# Python comments

## Scope

All Python source files.

## Requirement

Python source files **MUST** satisfy the project-defined comment requirements.

## Why?

Consistent comments improve source code readability, maintainability, and understanding of the project structure.

Standardized comments allow developers and automated tools to quickly identify the purpose of source files and ensure consistent documentation across the codebase.
