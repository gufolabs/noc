# Simplify implementation

## Scope

This requirement applies to all refactoring changes.

## Requirement

Code **SHOULD** be kept as simple as possible while preserving required functionality.

Refactoring **SHOULD** reduce unnecessary complexity, indirection, and cognitive load.

New abstractions, layers, or patterns **MUST NOT** be introduced without a clear justification.

## Why

Simple code is easier to understand, maintain, test, and modify.

Unnecessary complexity increases maintenance cost and makes future changes more error-prone.
