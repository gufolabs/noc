# Code Quality Standards

## Scope

All source code developed as part of the NOC project, regardless of programming language.

## Requirements

NOC **MUST** maintain consistently high code quality.

All source code **MUST** satisfy the common code quality requirements.

Source code written in a specific programming language **MUST** also satisfy the corresponding language-specific requirements.

Language-specific requirements **MAY** extend, but **MUST NOT** weaken, the common code quality requirements.

## Why?

Consistent code quality improves readability, maintainability and long-term sustainability of the project.

Well-defined coding standards make development, code review and automated verification more predictable for both human contributors and AI-assisted tools.
