# Markdown Quality Standards

## Scope

All Markdown files developed or maintained as part of the NOC project.

## Requirements

All Markdown files **MUST** satisfy the Markdown quality requirements.

## Why?

Markdown quality standards ensure consistent formatting and reliable processing of Markdown files.

They improve readability and maintainability of Markdown artifacts.
