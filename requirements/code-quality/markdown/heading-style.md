# Heading Style

## Scope

All Markdown files containing headings.

## Requirement

ATX-style headings **MUST** be used.

Example:

```markdown
# Heading Level 1

## Heading Level 2

### Heading Level 3
```

Setext-style headings **MUST NOT** be used.

Example:

```markdown
Heading Level 1
===============

Heading Level 2
---------------
```

## Why?

A single heading style keeps Markdown structure predictable and reduces unnecessary formatting variations.
