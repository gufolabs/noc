# List Formatting

## Scope

All Markdown files containing lists.

## Requirement

Unordered lists **MUST** use the `-` marker.

The `*` and `+` markers **MUST NOT** be used for unordered lists.

Ordered lists **MUST** use numeric markers.

All elements within the same list MUST use consistent punctuation.

List elements written as complete sentences MUST end with a period.

List elements written as fragments MUST NOT end with punctuation.

## Why?

A single list style reduces formatting variations and keeps Markdown files consistent across the project.
