# Common Code Quality Standards

## Scope

All source code developed as part of the NOC project.

## Requirements

All source code **MUST** satisfy the common code quality requirements.

Common code quality requirements **MUST** apply to all supported programming languages.

Language-specific requirements **MAY** define additional quality standards where appropriate.

## Why?

Common quality standards establish a consistent baseline across the entire codebase.

They promote predictable development practices and reduce the cognitive load when working with different programming languages.
