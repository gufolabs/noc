# Syntactic Correctness

## Scope

All source code.

## Requirements

Source code **MUST** be syntactically correct.

## Why?

Syntactically incorrect code cannot be parsed, analyzed or executed.

Ensuring syntactic correctness is the minimum quality requirement for any source code.
