# Code Complexity

## Scope

All source code.

## Requirements

Source code **SHOULD** have low complexity.

Code **SHOULD** avoid unnecessary complexity caused by:

- deeply nested control flow;
- excessively long functions or methods;
- excessive branching;
- duplicated logic.

Complexity metrics **SHOULD** be measured automatically where practical.

## Why?

Low complexity improves readability, maintainability and reduces the probability of defects.

Measurable complexity allows the project to identify areas requiring refactoring.
