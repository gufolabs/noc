# NOC Requirements

## Scope

These requirements apply to all activities, assets and artifacts related to the NOC project.

The requirements cover:

- source code and software components;
- technical decisions and engineering practices;
- documentation and publications;
- community and public communication;
- marketing and branding materials;
- releases and delivered products.

## Requirement

All NOC project activities, artifacts and decisions **MUST** comply with the requirements defined in this requirements graph.

Requirements **MUST** be maintained as a structured and traceable part of the NOC project.

## Why?

NOC is designed as a long-lived open-source project.

A structured requirements graph provides a shared understanding of project expectations and allows contributors, reviewers and automated tools to make consistent decisions.

Maintaining requirements as a graph makes project knowledge explicit, traceable and easier to evolve.
