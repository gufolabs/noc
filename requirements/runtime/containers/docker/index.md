# Docker Runtime Requirements

## Scope

Docker-compatible container environments.

## Requirements

NOC **MUST** support Docker-based deployment.

Supported Docker environments **MUST** provide:

- Docker Engine compatibility;
- Docker Compose compatibility;
- OCI container runtime compatibility.

The minimum supported Docker versions **MUST** be defined for each supported Docker environment.

## Why?

Docker is the primary container ecosystem used for NOC deployment, development and demonstration.
