# Debian 12 (Bookworm) Runtime Requirements

## Scope

Debian 12 (Bookworm) operating system as a runtime environment for NOC.

## Requirements

NOC **MUST** support installation and operation on Debian 12 (Bookworm).

The NOC runtime environment **MUST** remain compatible with the standard Debian 12 package ecosystem and system libraries.

## Why?

Debian 12 provides a stable long-term supported Linux environment widely used for server workloads.

Supporting Debian 12 provides a predictable and conservative baseline for production deployments.
