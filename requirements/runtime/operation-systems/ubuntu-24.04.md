# Ubuntu 24.04 LTS Runtime Requirements

## Scope

Ubuntu 24.04 LTS operating system as a runtime environment for NOC.

## Requirements

NOC **MUST** support installation and operation on Ubuntu 24.04 LTS.

The NOC runtime environment **MUST** remain compatible with the standard Ubuntu 24.04 LTS package ecosystem and system libraries.

## Why?

Ubuntu LTS releases are widely adopted in enterprise and cloud environments.

Supporting Ubuntu 24.04 LTS provides compatibility with a broad range of deployment platforms and infrastructure providers.
