# Debian 13 (Trixie) Runtime Requirements

## Scope

Debian 13 (Trixie) operating system as a runtime environment for NOC.

## Requirements

NOC **MUST** support installation and operation on Debian 13 (Trixie).

The NOC runtime environment **MUST** remain compatible with the standard Debian 13 package ecosystem and system libraries.

## Why?

Debian 13 represents the current Debian stable generation and provides a modern server platform with long-term maintenance expectations.

Supporting Debian 13 allows NOC to use current system components while maintaining compatibility with the Debian ecosystem.
