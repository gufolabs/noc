# x86-64 Architecture Support

## Scope

x86-64 hardware architecture used for NOC deployment, operation and development environments.

## Requirements

NOC **MUST** support execution on x86-64 architecture.

The supported x86-64 environment **MUST** provide the required CPU capabilities defined by NOC runtime requirements.

Specific instruction set requirements **MAY** be defined separately when required by performance optimization or dependency compatibility.

## Why?

x86-64 is the dominant server architecture with broad hardware availability, mature tooling support and extensive ecosystem compatibility.

Supporting x86-64 provides predictable deployment options for a wide range of production environments.
