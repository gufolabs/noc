# ARM64 Architecture Support

## Scope

ARM64 hardware architecture used for NOC deployment, operation and development environments.

## Requirements

NOC **MUST** support execution on ARM64 architecture.

The supported ARM64 environment **MUST** provide the required CPU capabilities defined by NOC runtime requirements.

Specific instruction set requirements **MAY** be defined separately when required by performance optimization or dependency compatibility.

## Why?

ARM64 is becoming an important platform across both developer and server environments.

ARM64-based macOS systems are widely used by developers, and native ARM64 support improves development efficiency by allowing developers to use their primary working environment without additional compatibility layers.

ARM64 is also an emerging server platform with rapidly growing adoption, providing a promising and expanding deployment option for future infrastructure.

Supporting ARM64 ensures NOC remains compatible with modern development environments and evolving server platforms.
