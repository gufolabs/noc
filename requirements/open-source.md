# Open Source Requirements

## Scope

All source code, artifacts, processes and activities published as part of the NOC project.

## Requirements

NOC **MUST** remain an open-source project.

The source code **MUST** be publicly available.

The project **MUST** provide transparent processes for development, contribution and collaboration.

The project **MUST** clearly define the terms under which the software can be used, modified and distributed.

The project **SHOULD** encourage community participation and external contributions.

## Why?

Open source is a fundamental principle of NOC.

Public availability of source code, transparent development and community collaboration increase trust, improve quality and allow the project to evolve independently.
